Inside the Machine: Fuzzy Logic Systems

Fuzzy inference is a computational method that models complex decision-making rules mimicking human reasoning, allowing for fluid boundaries instead of binary "true" or "false" thresholds.

1. Fuzzification Process

Valence and arousal dial values are mapped onto membership distributions. We model these sets using overlapping triangular membership functions (`low`, `medium`, `high`). This means an arousal score of 4.2 could represent a mix of 40% `medium` energy and 25% `low` energy simultaneously.

2. The 9-Rule Base

A rule compiler processes these overlapping variables using fuzzy logical intersections (AND operations). For instance: "If Valence is Low and Arousal is High, THEN target energy is High, target valence is Low, and target tempo is High." All active rule outcomes are mathematically combined.

3. Defuzzification & Vector Match

The combined output membership area is integrated using the mathematical Centroid method to find its center of mass. This outputs float features between 0.0 and 1.0. A weighted Euclidean distance maps this target to songs in our library, ranking them by match percentage.
